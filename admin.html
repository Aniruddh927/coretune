Enter the admin password to edit prices, availability, and images. GitHub access is handled securely on the server — no token needed in the browser.

How this works
  1. The owner sets the password and GitHub access in Netlify: Site settings → Environment variables → add ADMIN_PASSWORD and GITHUB_PAT.
  2. Enter the shared password here once — it's remembered on this device.
  3. Saving sends your changes to a serverless function that commits to GitHub with the owner's token. The token never touches a browser.
